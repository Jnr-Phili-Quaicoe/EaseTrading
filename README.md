# EasyLearning.edu — Python Flask Version

## Run on Windows

1. Open this folder in VS Code.
2. Open Terminal > New Terminal.
3. Run: `python -m pip install -r requirements.txt`
4. Run: `python app.py`
5. Open: `http://127.0.0.1:5000`

## Deploy on Render

Upload the whole folder to GitHub. In Render, create a new Web Service from the repository. The included `render.yaml`, `requirements.txt`, and `Procfile` contain the required settings.
